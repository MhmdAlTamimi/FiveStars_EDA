# Interactive Dashboard — NYC Taxi Zone Heatmap

An interactive Shiny dashboard that visualizes trip counts and revenue across NYC taxi zones on a Leaflet map. Zones are coloured by revenue or trip volume, with hover tooltips showing per-zone statistics and KPI cards at the bottom summarizing totals.

## How to Run

All commands assume the working directory is `FiveStars_EDA/` (the project root).

### Step 1 — Prepare the aggregated data

This reads the cleaned dataset and produces a per-zone summary used by the dashboard at startup.

```r
setwd("path/to/FiveStars_EDA")
source("InteractiveDashboard/prep_dashboard_data.R")
```

This creates `Output/dashboard_agg.parquet`.

### Step 2 — Launch the dashboard

```r
shiny::runApp("InteractiveDashboard/dashboard_map.R")
```

The app opens in the default browser. Use the controls in the top-left to switch between pickup/dropoff zones and between revenue/trip count colouring.

## Dependencies

All required packages are installed automatically when the scripts run if they are not already present. The full list:

| Package | Used For |
|---------|----------|
| `arrow` | Reading/writing Parquet files |
| `dplyr` | Data aggregation |
| `shiny` | Web application framework |
| `leaflet` | Interactive map rendering |
| `sf` | Spatial geometry (zone polygons) |
| `scales` | Number formatting (commas, currency) |
| `htmltools` | HTML tooltip labels |

## Required Files

| File | Location | Source |
|------|----------|--------|
| `cleaned_data_final.parquet` | `Data/` | Produced by the cleaning pipeline in `Analysis/` |
| `NYC_Taxi_Zones.csv` | `Data/` | TLC zone boundary polygons (WKT geometry) |
| `taxi_zone_lookup.csv` | `Data/` | Zone name and borough lookup |
| `dashboard_agg.parquet` | `Output/` | Generated by `prep_dashboard_data.R` (Step 1 above) |
